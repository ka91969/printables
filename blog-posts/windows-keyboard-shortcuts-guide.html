Windows Keyboard Shortcuts: The Hotkeys That Save Hours Every Week

« Back to all articles

Many people reach for the mouse for almost every window and text action, even though the keyboard is often faster for common tasks. The shortcuts below are the ones worth memorizing first. They are organized the same way as the Printable Windows Keyboard Shortcuts Cheatsheet, which covers three pages of hotkeys for Windows 11 users, sysadmins and developers.

System navigation

  • Win + E opens File Explorer.
  • Win + X opens the Power User menu, with Terminal, Settings and Device Manager.
  • Win + I opens Settings.
  • Ctrl + Shift + Esc opens Task Manager directly.
  • Win + L locks the screen. Use it before stepping away.

Window snapping and task switching

  • Win + Left or Right snaps the active window to half the screen.
  • Win + Z opens Snap Layouts so you can choose a grid for several windows.
  • Win + D shows the desktop, and pressing it again restores your windows.
  • Alt + Tab switches between open windows.

Virtual desktops

Virtual desktops keep work contexts separate, for example one for email and one for a project. Use Win + Ctrl + D to create a new desktop, Win + Ctrl + Left or Right to move between them, and Win + Ctrl + F4 to close the current one.

Text, clipboard and screenshots

  • Ctrl + Left or Right moves the cursor one word at a time.
  • Ctrl + Shift + Home or End selects text to the start or end of a document.
  • Win + V opens clipboard history, so you can paste something you copied earlier.
  • Win + Shift + S captures a region of the screen.
  • Win + G opens the Game Bar, which includes a screen recorder.

Browsers and terminals

In most browsers, Ctrl + T opens a new tab, Ctrl + W closes one, and Ctrl + 1 through Ctrl + 9 jump to a tab by position. Ctrl + Shift + N opens a private window. Be aware that Ctrl + Shift + T means "reopen closed tab" in a browser but "new tab" in Windows Terminal, so the context matters.

Win + R commands worth knowing

Press Win + R, type one of these, and press Enter:

  • services.msc: manage background services
  • devmgmt.msc: open Device Manager
  • ncpa.cpl: view and change network adapters
  • msconfig: control startup and boot options
  • resmon: open Resource Monitor
  • sysdm.cpl: open System Properties

Make these changes only if you understand them. Changing services or boot settings can affect how your PC starts.

How to learn them without overwhelm

  1. Pick three shortcuts you would use this week, such as Win + Left, Win + V and Win + Shift + S.
  2. Use them deliberately for five working days.
  3. Add three more the following week.

Keep the full list where you will see it. The Windows Keyboard Shortcuts Cheatsheet is built for that purpose. For more on reference formats, see our printable cheatsheet guide.

Building muscle memory one shortcut at a time

Knowing a shortcut and using it automatically are different skills. Most people read a list of hotkeys, feel they understand it, and then reach for the mouse out of habit. The reliable way to build the habit is to choose a small number of shortcuts that match your most frequent actions, use them deliberately for a week, and only then add more. Three shortcuts used every day will do more for your speed than thirty shortcuts read once and forgotten.

I would suggest starting with the actions you repeat most, such as switching windows, snapping a window to one side, and taking a screenshot of a region. These are the moments when the mouse slows you down most, so they produce the fastest visible improvement.

Accessibility shortcuts worth knowing

Windows includes accessibility tools that are useful for everyone, not only for people who rely on them. The Magnifier can be opened with the Windows key and the plus sign, which helps when reading small text on a presentation screen or a dense spreadsheet. Narrator, which reads screen content aloud, can be toggled with Windows key, Ctrl and Enter. Sticky Keys lets you press modifier keys one at a time instead of together. Knowing these options also helps you support colleagues or family members who need them.

Working in the terminal and browser

The shortcuts that differ by context cause the most confusion. Ctrl plus Shift plus T means one thing in a browser and another in a terminal, so it is worth learning the context rule rather than the shortcut alone. In a browser, Ctrl plus Shift plus T reopens the most recently closed tab, which is a lifesaver after an accidental close. In Windows Terminal, the same combination opens a new tab. Keep this distinction in mind when you switch between applications, and the confusion disappears.

Using the Win plus R commands responsibly

The Run dialogue is a powerful tool for experienced users and IT professionals. Commands such as services.msc, devmgmt.msc and sysdm.cpl open management windows directly. The responsibility that comes with that power is important. Services and startup settings can stop a computer from working correctly if changed carelessly. Open the window, read the options, and change only what you understand. If you are unsure, note the current setting before you change it, so you can restore it.

Keeping your shortcut list current

Windows updates occasionally alter how a shortcut behaves, and new features appear over time. Review your printed reference once every few months, and remove the shortcuts you never use. A shorter, accurate list is more useful than a long one that no longer matches your system.

Practising shortcuts during real tasks

Shortcuts stick best when they are practised during real work rather than in isolation. Choose a task you already perform, such as sorting files or preparing a document, and try to complete it using only the keyboard for ten minutes. Notice the moments when your hand reaches for the mouse, and decide which of those moments deserves a shortcut. This approach ties each shortcut to a situation you recognise, which makes recall faster.
